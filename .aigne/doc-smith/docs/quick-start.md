# Quick Start

This guide provides a fast-paced introduction to ExcelJS, designed for developers who want to start creating spreadsheets immediately. By following these steps, you will install the library, write code to generate a simple `.xlsx` file, and save it to your disk, all within a few minutes.

This section is divided into two main parts. It is recommended to follow them in order to ensure all prerequisites are met.
